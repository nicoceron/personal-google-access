Privacy practices

This notice describes the private Personal Codex and Claude Google integration. It is operated by its sole owner for personal tasks and does not offer public account registration.

Data and purpose

The approved Google permissions allow Drive file access and management, Gmail reading, composing, sending and modification, calendar reading, and event management. Actual access is limited by the owner's requested task and the active session's permissions.

Processing and sharing

The Google Workspace CLI communicates with Google APIs. Task-relevant content may be supplied to the selected Codex or Claude service under that product's normal account settings and data policies. This integration does not operate a separate public data collection endpoint or automatically grant another person access to the owner's Google data.

Personal credentials and Google access through this setup are authorized only for the owner's personal local Codex and Claude Code contexts. Other software, ordinary Claude Chat/Cowork, and employer-managed work are excluded.

Storage

OAuth credentials use the Google Workspace CLI's encrypted local credential storage and normal operating-system keyring backend. They are not published on this website. Task outputs may remain in the owner's local files or agent conversations according to the selected application's normal storage settings.

Control and revocation

The owner can revoke the app's Google access from the Google Account's third-party connections settings and remove local task artifacts through the applications that store them. Normal Google token revocation and account security controls continue to apply.

Google API data

Use and transfer of information received from Google APIs must comply with the Google API Services User Data Policy, including its Limited Use requirements.
